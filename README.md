# terraform-from-hyper-go
Аналог terraform для HYPER-V (гипервизор Windows)

Требования:
1. Работает с правами "Администратор", либо максимальные права на управление hyper-v локально + права на каталоги с конфигурацией ВМ, хранения HDD ВМ, инсталяционные диски для ВМ
2. Скопировать EXE-файл в каталог system32 или если каталог произвольный прописать его в переменной PATH
3. Консольную утилиту запускать только в командной строке, Posershell срезает заглавные буквы

```
Ключи утилиты:
-name     "<>" - в <> указать наименование ВМ
-vcpu     "<>" - в <> указать количество виртуальных ядер для ВМ
-ram      "<>" - в <> указать количество оперативной памяти в ГБ
-ram-type "<>" - в <> указать тип выделяемой памяти static/dinamic, в случае если dinamic необходимо указать 2 следующих параметра памяти
-ram-max  "<>" - в <> параметр для динамической памяти, это максимальное значение в МБ
-ram-min  "<>" - в <> параметр для динамической памяти, это минимальное значение в МБ
-switch   "<>" - в <> параметр для указания наименования виртуального коммутатора
-gen      "<>" - в <> параметр указывающий поколение ВМ - 1 или 2
-iso      "<>" - в <> параметр для указания каталога с инсталяционным iso-диском
-vm-path  "<>" - в <> параметр для каталога хранения конфигурации ВМ
-hdd-type "<>" - в <> параметр определяет тип диска dinamic/fixed
-hdd-path "<>" - в <> параметр для указания каталога хранения виртуального диска ВМ
-hdd      "<>" - в <> параметр используемый для указания размера ВМ (по умолчанию 40 ГБ)
-notes    "<>" - в <> параметр для ввода описания ВМ
```
Данные утилита написана для личного использования и распространяется без гарантий и ответственности...
